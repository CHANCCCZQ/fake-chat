# 对话工坊

双手机视角的微信聊天模拟网页。左边操作对方，右边操作自己，同步呈现同一段对话。

## 使用

工程基于 **Vite 8 + React 19 + TypeScript**，使用 Node.js 24 LTS 和 npm 11。

```sh
nvm use
npm ci
npm run dev
```

打开开发服务器提示的本地地址。`npm run check` 执行格式、代码、类型和业务测试；`npm run build` 构建静态文件至 `dist/`，`npm run preview` 预览生产产物。

- [工程结构和开发约定](docs/engineering.md)
- [GitHub Pages 发布步骤](docs/github-pages.md)
- [基础 SEO、分享与上线后的收录检查](docs/seo.md)

已配好自动检查和 Pages 发布工作流：推送 main 后可自动构建发布，首次需要在 GitHub 仓库 Settings → Pages 选择 GitHub Actions。

## 操作

- 左侧「聊天分组」支持新建、切换、重命名；每组独立保存消息、头像昵称、设备设置及未发送内容。原有聊天自动迁移保留，删除的分组可从「最近删除」恢复。

- 左侧「消息时间」可指定模拟发送时间，或使用当前时间；消息间隔满 5 分钟或跨天时自动生成时间标签，点击可切换详细日期。消息旁的时钟按钮可单独调整时间。
- 输入文字，Enter 发送，Shift + Enter 换行。表情按钮添加 emoji。
- 「＋」支持图片、红包、转账和时间节点；也可在输入框粘贴图片。
- 在接收方点开红包领取，或点开转账收款 / 退还，会同步更新两侧卡片并自动插入关联消息。
- 悬停消息可编辑 / 删除；点击手机上方「＋」，选择任意两条消息间的位置，再从任意一侧发送。文字、表情、图片、红包、转账和时间都可插入，发送一次后自动退出插入模式。
- 左侧修改双方头像、昵称及独立的安卓 / iOS 状态栏配置。
- 顶部撤销 / 重做；清空与恢复示例同样可撤销。草稿自动保存在本浏览器。
- 先滚动到需要的位置，再截取所选手机当前画面；可复制或保存 PNG，不含手机外框与编辑控件。

安卓默认状态栏按用户提供的截图实现。iOS 与红包、转账状态使用常见浅色样式；不同版本、机型的精确差异需通过实机截图继续校准。

聊天与图片只在当前浏览器中处理，不连接微信，不执行资金交易。清理浏览器站点数据会移除草稿。图片会压缩为适合聊天显示的静态图片，GIF 取静态帧。图片过多导致本地存储不足时会明确提示。

## 参考素材

按用户指定参考 [gaopengbin/wechat-dialog-generator](https://github.com/gaopengbin/wechat-dialog-generator)；所用红包、转账及输入栏图标清单见 `public/wechat/ASSETS.md`。其余界面与消息联动在本项目实现。

### 通用 UI 组件

设置与编辑界面使用 shadcn/ui New York 组件（Radix），源码在 `src/components/ui/`，保留上游 MIT 许可。`components.json` 和 `@/` 别名已配置，后续可以按需添加组件。主题和少量尺寸适配集中在 `src/ui.css`；Tailwind 不加载 Preflight，以保护独立的微信仿真样式。日期时间统一使用 Calendar + Popover，提供中文日历与年月切换；时分输入保留原生控件语义；手机系统、移动网络和消息状态使用 shadcn/ui Select。
